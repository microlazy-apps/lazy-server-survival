# lazy-server-survival

懒猫微服包装：[pshenok/server-survival](https://github.com/pshenok/server-survival) — 3D 浏览器塔防游戏，扮演云架构师，扛住流量与 DDoS。

## 安装

懒猫商店搜 "Server Survival" 一键安装。

## 使用

装好访问 `https://server-survival.{你的微服域名}`，开始游戏。

纯前端，无后端、无登录、无数据收集。游戏进度只存在浏览器本地。
